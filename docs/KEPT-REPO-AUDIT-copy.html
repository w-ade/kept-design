What makes this repo feel crowded today?

Three kinds of things share one root without labels: the product (src/, public/), a second internal app plus roadmap machinery (dashboard/, docs/roadmap/, scripts/roadmap.mjs), and files that are copies of another repo (src/kept/, public/collections/). Nothing in the file names distinguishes them, and half the tracked files are seed images. Untracked bulk (node_modules, .delta, dist) adds to what you see on disk, though git ignores it.

The clutter is mostly organizational; the genuine technical risk is narrower: src/kept/ is overwritten by a script, and it already contains one local edit that the next run will erase. Planning pages (/map, /ios, /todo) also ship in the public product, and several docs are stale. Much of the rest (mock storage, tracked images) is temporary because the backend is not built yet.
